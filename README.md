# Library

A simple library management application built with HTML, CSS, and JavaScript.

## Features

- Add new books to a library
- Display all books in a card-based layout
- Remove books from the library
- Toggle a book's read status
- Unique ID assigned to every book using `crypto.randomUUID()`
- Responsive two-panel interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

1. Fill out the book form on the left side of the page.
2. Click **Add Book** to store the book in the library array.
3. Click **Display Books** to render all books on the right side of the page.
4. Use the **Remove** button to delete a book.
5. Use the **Change Read** button to toggle a book's read status.

## Notes

- Books are stored in memory only.
- Data is not saved after refreshing the page.
- This project was built as part of The Odin Project JavaScript curriculum.
